# Estado del simulacro

El simulacro es una condición necesaria, no suficiente, para un piloto real.

Incluso con 6/6 pruebas superadas, el piloto real seguirá bloqueado hasta que exista saldo EUR, preflight real `validate=true`, certificado vigente, PAPER/forward con evidencia suficiente, reconciliación limpia y revisión humana explícita.
